# 天命道人：旧识、五色命格与命劳叹

蓝袍光滑脸半黑半白须，船在高览真韩旁，孟认收留过戒杀道人萨仁波娃、看其五色命格旧人。此章是回忆认人非新占出具体命运；不能合此前海上未名青年道人或所有天命名号。孟混沌脱古气纠缠上前actual问安，33他也是法身仍内问，未给确定境阶。道人actual不好命中劳、命定哪逃，平淡沧桑磨锐得某种安宁；命定说不全书众生毫无自由公理。建议语平有叹，孟尊前辈与意外在船的探问相接，不先填岛主或幕后操纵身份。末59天命玄鸟古语不是他actual发言。证据v06-c0061:p0031–p0037。

身份索引现用tianming_daoren，旧事件tian_ming_dao_ren亦指此旧角色，不另建人物；机器别名统一留全书终审。旧命定叹可接本章平淡劳命，但不证绝对宿命或死期。证据v03-c0241:p0051；v03-c0244:p0058；v04-c0401:p0057–p0058。
