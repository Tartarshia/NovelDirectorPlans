# 霍以鞭识旧假太乙与元始名推测、名感限度

云月实际唤沉思霍，霍命流裳取太乙留下神兵，流裳笑夸云月含上次旧事为表演暗锋，云月嘟嘴抱怨。16霍亲昵看撒娇后问旧材料，17云月实际列四类材料，内部篆名非四剑新声。19流裳真实取铁黑竹节鞭重得艰行，不新造鞭/神兵丢失。

霍实际接赶山鞭看与复述罗教旧情报21；传说彼岸特征不正式境界，蛊神旧战不是本章新杀。22/23侍妾惊比较公子逊为焦评，24云月据鞭认元皇=旧太乙韩别身份。25霍估冒韩名为假、恐怕仙迹元始天尊是推断，未真古神本尊/真韩=苏。27幽湖霞帔等倒吸与内评，28元始尊号解释非真正神新声。

云月29旧认人仙，30霍实际纠地仙且媲天，非孟新晋天仙；31–33霍内明昔道士话因果、千面险反噬与得罪真正天仙韩，非韩本人到场。34云月惊修速未来天仙预测，36流裳怯问报复，37霍实际命打探炼何物未结果。38云月劝39霍罗教法王公事与老母护反问，40故意提名邀惠，41有想便感仅名头吸注意不无代价读全部思想；未老母实际降力读心/承诺护。42云月实际恭顺答。证据v06-c0138:p0011–p0042。
