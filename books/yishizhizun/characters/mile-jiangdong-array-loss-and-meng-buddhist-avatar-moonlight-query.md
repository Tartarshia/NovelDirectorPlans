# 弥勒实破城禁与孟僧身净土问药师

弥勒莲台裹众实入江东，信众感应齐诵53救世弥勒佛号，不弥勒自己领喊或阿佛新口。报身散琉璃成多佛相连界真瓦解多城禁阵削该区众生力，图对应东海渐暗消，局部实损不全周/长乐已失。57四色剑气实遥劈弥勒，是17遥阻计划落地尚无击中退敌结果。58孟本尊仍台分俊僧身默念月光尊号、直接入东方琉璃净土，未给默念逐字不补口。59见月光60僧身孟实际问药师王佛何处，月光未答药师未现、位置未明，争盟行动已进而盟未结成。

少羲先惊疑后信任，齐声领诏肃正；孟元皇发令稳庄严，不借元始本尊声音。牛粗豪吐唾低吼到大笑自恃，旧敌少年哪吒细牙笑问轻快有旧账，不预演新胜负。青丘摸冷热枪沉吟，鹏蛟只战意动作。江静候信息不躁，语音通道与现场分层，警报一来利落降城。陆苏无声对视，虚苦笑愿帮却不敢定刀；弥勒慈笑佛相与实破禁并存，群信众诵号铺地域感。孟封台本尊和净土僧身并行切镜，问药师简直而非已找到。

证据v07-c0018:p0001–p0060。
