# 于齐玉虚记名、三年考校与照见宿世的未来条件

1/2于齐误疑叹息因资质心性差，没获知旧张符因由，非孟当面判二人不合格。3孟actual知下界飞升与昆仑有缘；4–6秘密被知的惊与转念内心，不孟失忆后刚发现来历。7金光莲缩成实金册实际，但8/9识作虚空造物与11怀疑跨苦海末段是于齐所想，10古籍造物体悟说明不能当孟本章已正式造化；12孟actual明确改变物质与真虚空造物有距。

传承层次、金册实物与精神秘法并列；不把孟的离去改成带两人进宫，不编号码或群内实际招呼。

孟负手踱步平淡提缘，淡笑解误读、挥手定记名和考校，飘渺传秘法后悄离，不用炫耀造化的声线。于齐由忐忑秘密曝光到瞪眼、狂喜叩谢，敬畏真实但保成人判断。于稳下来解释资源历练并先顾妻，齐主动检索比较、喜商城又内嫌运费，收到惊快带师门荣誉，不演为贪便宜无修道心。到长乐齐初见建筑失神、闲人地方自豪和于内心政治风险判断三层并置；末忧虑收住，没提前战斗。
