# 孟道一照归路、陆压葫芦与八九双兵返江东

56日入阵似连远净土须弥四禅上古佛托因果灯，58–60源名燃灯造化圆满且为救佛提前醒，不本章新晋彼岸或所有古佛都醒。57灯真把无灵智皇尸困仅因果线异宇宙、暂找不回同时照稳万佛，不尸已永久死/具有自主活灵智。61前因果宇宙孟内识后目道一灯N，62黑白灯沿联系真照归路，未明皇尸已走出。63朱红葫芦毫光眉眼物双白射日，64燃灯actual陆压由65宏声锚，66叙昔元始封万古陆压竟助皇玉虚是燃灯讶，不本章重新被封/陆压本人新嘴。未射中杀燃灯结果；67孟八九实际再到江东双手持绝刀智慧剑，当前兵已在八九，不同一实物同时仍江和合体手，取回过程没写不补。S08至55阵攻守，S09从56燃灯圆满者提前醒、因果斗法与陆压插战起。

孙仅棒强势蛮横凶暴不补本人新口，广印沉重和孙碰撞余波让孟主动保民必须显选择代价。牛逃路反复被堵别演已出阵，广师兄认知与牛咬牙都口内留审。真佛低吼接旧场到真灰灭、教堂信徒惊主死为实后果，别提前按全投影永根除。佛尊旧敌内叹、笑僵莲萎舍利裂到燃灯救场，皇尸被因果困因无智须保眼死形。主阵孟点灯破解，燃灯庄严声讶陆压与未交锋结果、八九双兵回江东作层层升级悬念，兵器转手不补不存在对白。
