# 390章四象殿虚盒：见到与取印分开

37白殿赤柱青砖黑瓦，案上温润通透虚玉盒半开；38地火风水与赤青黑白生灭如沸物质不存虚空难立，孟据此判断恐怖。若为法宝神兵即传说三霄之一陷入亦化血是条件比喻，不真实三霄出现/死亡。

39孟熟封神恍悟四象印对应它并到殿门，原文当前没有直接喊完整法宝名，暂不用后文补名、不给拟人盒声。40唐镜袭点向止，四象真意/盒未领取、开天也未取得。显示危险与知识辨认可以构成导演悬念，无需偷偷提前安排奖励。证据：v04-c0390:p0037–p0040。

## 391章：实体印真实抓取与一次真意，新状态不再未取

15/42先抓摄/迈步均镜阻未领，79才真正抓四象印遁往开天80精神探入汲一次真意。虚幻玉盒形印可携拿，不以虚字就否认实收对象；真意得不全印熟，81为争开天可弃制造混乱是未做计划，现未抛弃/送秦汉楚。玉虚殿14/39爆战无损，远界灾害与三霄设喻不本场真灾。证据：v04-c0391:p0015、p0042、p0079–p0081。
