# 孟旧忆与公众战绩、巴彦游人和内心释依

1/2引号由3明确脑内念，4–9无武无法抗传说诡瞳、护友复小桑等均孟内忧，不当空中逐句发言或敌人当前都到。齐11–14实际以若非互信会疑谋诛、抗拒即依赖、昔无武仍活反问；阴谋是换他人建议的条件比拟，不齐承认正谋杀孟。15内念互辩引16–21，各方论据同一孟心不是外来人格附身；撑几年月光青帝护、未来可能契机均其预期无保证。23嘴唇动未成言、24内问，26齐实际让本人决定27赤星洪流势离去，不强制剥功或接受孟已答允。

28孟叹后反事实：若像斩过去断未来那样明确有成功可能便会尝试，但当前放弃也可能徒劳；“自己已然尝试”在若条件内，不他此前已经试弃武。30实际走广陵江外、31最后见小桑地点回忆，32她挣扎输旧忆不新小桑实体声。36由当前线索推她留后路、37性情回想、38灯下白裘素裙归来为孟希望中的妖女形象，未本章已复活。39–41一串引号由42思绪翩飞界定内问，猜她寄希望为何信己、感情/实力期待仍问，不小桑本人揭遗嘱。孟依然回到武道依赖，43实际夜月过江北行。

又一夜到旧巴彦谷今湖，斩狼王、湖上白莲青灯为记忆，不当前狼王复活重战或小桑坐对岸。50–56两未名游客交替实际问答：A问谷、B讲战绩，A问改湖、B讲天魔大战、A求合照、B问何以放松、A答人皇遗族助并自夸名剑捭阖。游客说据说传说不少是公共传闻，不能作遗族传说精确数量；自夸称号非确认本名及真实战力。求拍照是请求无完成照片动作。57孟实际微笑后内问别人眼中自己；58–61自记与游人实力战绩视角不同，旧白衣少女只浮现记忆并未现身，个人经历、无法忘怀让他意识自我非全等于战力。

62孟实际离湖走遍南北旧址追己，不仅仍站湖畔脑想。63/64报信少林/背伤者一剑一人的旧事不新战役，又都分实力好处与难忘热血快意；65少林微力时珍重师父小师弟为回忆，不玄悲真慧当前新嘴。66内心渐宁静、67无武我会怎样内问、68崖边吐气决断。69回悟师玄悲放下破法我是孟体会，不师此刻远传实际讲话。70/71那就试及无武还是不是我是内心决定，此时还未削功；既没忘爱憎也不是要求清空所有亲友情感。

孟内诸论互辩仍同一声线，开头执武抗拒、被齐戳中后欲语不成；齐越严肃越平淡而信任，最终交还决定不威逼。广陵月下萧瑟、巴彦游人轻松笑谈拍照形成反差，孟微笑听见公众自己后转珍重私忆、南北旧路逐渐宁静，崖边吐气不豪叫胜利。赴岛朗求、正色请求到平静确认，碧脱口惊、沉默再问，不带幸灾乐祸。削功后孟空荡惊惧、接着衣袍难维的内心尴尬以短喜剧落地，碧呆后给衣，不添羞辱对白、情色镜头或主动暴露动机。
