# 法身能力与绝刀内争：第六卷2章

孟虽证不灭元始身且时空勉强唯一，但未遍布时空，只略具传说、彼岸特征。不要因宇宙异象或切断未来控制，就提前给予后续境界全部能力。第15段明确列出边界：

| 当前有 | 当前没有 |
| --- | --- |
| 无微不至之能 | 拔于九重天 |
| 真实界外借气息改变天地法则 | 无处不在、遍布时空 |
| 真实界内放大某方面天地法则 | 投影不灭则己身不死 |
| 感受长河冲刷与命运流动 | 短暂跳出长河、追溯过往、照见未来 |

因此跨界50须道一印、绝刀与虚空印协作闯重阻，不一念无阻随意遍所有世界。17地仙水平描述的是当前绝刀输出，并不证明孟自己已晋地仙。52天下顶尖新名是本界格局地位，不正式传说或彼岸认证。

10–14刀由雷池与雷神遗蜕炼、蕴神霄九灭，暗藏雷神＝魔佛的印记。霸王陨落不只未来念：昔对阿难造化、轮回弱的知识令未防未来夺，轮印来世突袭配合围杀、刀短暂失控逼自爆；当时阿难尚非彼岸。保时代区别，不用现在魔佛彼岸去否定昔时源层次。

霸王炼制者烙印万年察敌印，隐忍关键阻孟悟神霄九灭，在孟斩过去时压敌印抵轮印；当前双印争有同尽倾向，非一时一日已终。16孟暂不能插手，计划等末局抹敌印、取霸王残执念正常转世，若后人愿才收徒偿因果。执念不是真灵魂魄，正常转世不等原霸王复活归来，也不能配霸王本尊当前口白。

导演建议：刀的霸气能隔杀意但保输出限制和未全醒，不将谈判场演成无限胜过斩仙飞刀；孟放松表面仍右按柄有戒备。历史信息由旁白承接，潜印无文本台词不给器灵新增长篇争吵。证据：v06-c0002:p0009–p0019、p0050–p0052。
