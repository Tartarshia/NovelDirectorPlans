# 少林旧同辈与迎客视角：344章

## 未具名知客僧与武僧

4两黄袍知客一起低佛号迎请苏施主，为真字辈8自己七八窍；双人同说可保合声但各人名年龄声线未明，不强合真本真妙。6/7看青年潇洒与气内敛兼，8比较复杂9失能说会道孟感知刻意沉默。稳定声演员未能分两人时保双知客实体与待录音处理。

25–33武僧罗汉拳练声、分心被教僧喝，教僧也关切迎宾；30狂刀空双手无刀惊、31法身下一刀难逃之号影响弟子兼学阿难刀、32/33榜样感是群体观察。不是本章孟击杀全体法身下或弟子已全练成刀；没有具体哼哈喝骂逐句台词不补写。

## 真本与真妙

34门外熟悉武痴真本、授业真妙；35前者天人合一后者天人交感，36都未突破等待积累。37妙不自然移目、本微点，孟38未打招呼，39两人叹层次早不同。非真本外景/真妙宗师、非未友好就仇恨，羡差与尴尬在动作里。稳定ID zhen_ben / zhen_miao 与知客匿名组分开。

证据：v04-c0344:p0004–p0009、p0025–p0039。
