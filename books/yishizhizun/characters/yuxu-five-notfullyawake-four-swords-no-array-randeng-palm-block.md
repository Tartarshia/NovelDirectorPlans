# 玉虚五位未全醒、无阵图四剑加印剑合拦燃灯掌

淡金琉璃大掌压来将少玄羲娥隔入星线因果宇宙，13/14认燃灯阻高以二人内思/可低问待录，不燃灯当前自己讲话。16孟在东方琉璃证相对受护与山河图若护高会阻勾无穷高处是解释，不孟现在又在佛国突破。17四剑真合阵18外见困掌19明确没阵图四剑只略削一掌须古印与智慧剑再加，不能记完整杀阵已灭燃灯。21广成天尊文殊赤精子玉鼎道行未彻底醒五人合力拦被逼提前返的燃灯，未每一剑具体主人源都给或五人已全醒峰/佛祖死。23少羲实祭末日舟24前准备冲出、29还在冲界，非已彻底逃出/船毁。24封天台自发动地权强山河图保护长乐，不宣31全仪补成功统天。

城中光柱九重与各地惊问热望，不提前用正式成功报喜旁白。燃灯掌压隔少羲冷因果宇，四剑仅削再印剑合拦层次要清，双守舟冲未出；民受惠喜忧交叠转黑棒危。袁怒你和内疑孟新境再识刀境分声，孟稳而自知只拖不逞胜，双远地武器高空战的空城保护清楚。金灯消余波后赵肃然进台取榜，三篆只字面呈、保动作未用的悬念。
