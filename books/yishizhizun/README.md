## 阅读与复核记录

- [逐章阅读记录](READING-LOG.md)收录保留到终审前的逐章发布与回补记录。
- [角色 wiki](wiki.md)：人物、关系、身份揭示、阶段变化及原文证据。正文保留逐次增补的历史记录，跨卷概览可从主要角色连续性索引进入。
